# Architecture

Backend-only view. The system also includes hardware and a phone app that live in a separate private repo; this doc only covers what's in this repository.

## End-to-end flow

```
[Phone app over HTTPS]
        │
        │  POST /v1/measurements        { device_id, barcode, weight_g, ... }
        │  GET  /v1/products/{barcode}  → { name, macros, ... }
        │  POST /v1/voice/match         (multipart wav/m4a, fuzzy-match against pantry)
        │  CRUD /v1/user-foods, /v1/pantry
        │
        ▼
[Caddy] ──── reverse-proxy ──▶ [api: FastAPI uvicorn :8000]
        │                              │
        │                              │ SQLAlchemy async
        │                              ▼
        │                          [Postgres 16]
        │
        └─── (auto-TLS via Let's Encrypt HTTP-01)
```

Migrations run as a one-shot `migrate` container on every deploy, blocking `api` until they complete.

## Core decisions

- **Frozen-once-resolved macros** — once a barcode → macros mapping is committed it's never silently recomputed. ([ADR 0007](adr/0007-frozen-macros-once-resolved.md))
- **No public product reads** — every non-health endpoint requires `X-Device-Key`. ([ADR 0009](adr/0009-no-public-product-reads-mvp.md))
- **Shared secret device key** — single long-lived key gates writes + reads in MVP. Per-user auth is future work. ([ADR 0011](adr/0011-shared-secret-device-key.md))
- **FastAPI + Postgres** — async I/O all the way down; Pydantic v2 schemas; Alembic migrations. ([ADR 0004](adr/0004-fastapi-postgres-backend.md))

## Code layout (api)

- `routes/` — thin FastAPI routers, one file per resource.
- `domain/` — pure functions, no I/O. Unit-tested in isolation.
- `repos/` — SQLAlchemy async, all DB access.
- `schemas/` — Pydantic request/response models.
- `voice/` — Whisper client + fuzzy matching against the per-user pantry.
- `auth.py` — `DeviceKeyMiddleware`. `/v1/healthz` is auth-exempt; everything else under `/v1/` requires `X-Device-Key`, or `X-Admin-Key` when `ADMIN_KEY` is configured.
- `app.py` — also registers the RFC 7807 exception handlers so every error (not just auth) is `application/problem+json`.
- `config.py` — `pydantic_settings.BaseSettings`. Refuses to boot with empty `DEVICE_KEY` outside `dev`/`test`. Optional `ADMIN_KEY` enables the admin auth path (used by the scraper).

## Wire contract

The contract is FastAPI's OpenAPI document. The canonical copy is committed at [`services/api/openapi.json`](../services/api/openapi.json) and regenerated by [`services/api/scripts/generate_openapi.py`](../services/api/scripts/generate_openapi.py). Errors are RFC 7807 `application/problem+json`. See [`API.md`](API.md) for endpoint reference.
